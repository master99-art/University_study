# 机械臂仿真

- 标准DH法：坐标系建在两岸的输出端，适合应用于开链结果的机器人
  - 树形结构与闭链的机构的机器人，连杆坐标系会产生歧义
- 改进型DH法：坐标系建在连杆的输入端
  - 对开链，树状，闭链结构的机器人都适用

###### 坐标系

旋转轴为z轴，有一个初始z0轴

x轴垂直当前的z轴，还要垂直之前的z轴

###### DH参数

- $d_{i}$：为沿着$\hat{Z}_{i-1}$轴从$\hat{X}_{i-1}$到$\hat{X}_{i}$的距离，与$\hat{Z}_{i-1}$的方向相同
- $\theta_{i}$：为绕$\hat{Z}_{i-1}$轴从$\hat{X}_{i-1}$到$\hat{X}_{i}$的转角，绕$\hat{Z}_{i-1}$正向转动为正
- $a_{i}$：为沿$\hat{X}_{i}$轴从$\hat{Z}_{i-1}$到$\hat{Z}_{i}$的距离，沿$\hat{X}_{i}$为正
- $\alpha_{i}$：为绕$\hat{X}_{i}$轴从$\hat{Z}_{i-1}$到$\hat{Z}_{i}$的转角，绕$\hat{X}_{i}$为正向转动为正

| $i$  | $\alpha i$ | $ai$ | $di$ | $\theta i$ |
| ---- | ---------- | ---- | ---- | ---------- |
| 1    |            |      |      |            |
| 2    |            |      |      |            |
| 3    |            |      |      |            |
| 4    |            |      |      |            |
| 5    |            |      |      |            |
| 6    |            |      |      |            |
| 7    |            |      |      |            |

得到DH参数后我们就可以使用DH参数转换来求出相邻坐标系的变换矩阵T0~T6，然后我们依次相乘就可以得到其从原始坐标系到末端的变换矩阵了

其矩阵的格式为：
$$
\left(
\matrix{
	r_{11} & r_{12} & r_{13} & p_{x}\\
	r_{21} & r_{22} & r_{23} & p_{y}\\
	r_{31} & r_{32} & r_{33} & p_{z}\\
	0 & 0 & 0 & 0}
\right)	\\
\quad 
其
\left(\matrix{	
    r_{11} & r_{12} & r_{13} \\
    r_{21} & r_{22} & r_{23} \\
    r_{31} & r_{32} & r_{33} \\}
\right)
是旋转矩阵：用于确定其末端的位姿
\\
其
\left(\matrix{	
  p_{x}\\
  p_{y} \\
  p_{z} \\}
\right)
是位移矩阵：相对于其T0坐标其末端坐标原点的位置
$$
