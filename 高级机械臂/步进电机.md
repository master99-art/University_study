## 代码解释

- 我在下位机配置的tar_angle 和 now_angle 全部都是没有考虑减速比的，电机直接转动的角度，在发送数据的时候我需要给上位机发送机械臂的关节角度，这样上位机就不需要考虑减速比的问题了

- 我使用的都是rad弧度制

- 我在串口使用了crc8校验方式，多项式是0x8c

  - crc8：我把全部字节都考虑进去了

- 在收发关节角度的时候我都扩大一千倍，所以无论是上位机和下位机都需要考虑接收和发送数据的时候扩大了一千倍

- 对于hand，我使用了判断的格式，1就是抓取，0就是不要抓取。他没有扩大一千倍

- 数据包格式

- $$
  {55 \quad aa \quad 00\quad ……\quad00\quad crc8 \quad 0d \quad 0a}
  $$

```C
unsigned char getCrc8(unsigned char *ptr, unsigned short len)//数据包 包含的字节
{
	unsigned char crc;
	unsigned char i;
	crc = 0;
	while(len--)
	{
		crc ^= *ptr++;
		for(i = 0; i < 8; i++)
		{
			if(crc&0x01)
                crc=(crc>>1)^0x8C;
			else 
                crc >>= 1;
		}
	}
	return crc;//返回计算结果
}
```
